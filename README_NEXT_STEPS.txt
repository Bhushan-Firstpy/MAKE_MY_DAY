MAKE MY DAY — MobileStudio-compatible source project
======================================================

Compatibility target:
- JDK 17
- Gradle 8.2
- Android Gradle Plugin 8.2.2
- Android SDK API 34

The project contains the approved V4 UI in app/src/main/assets/index.html.

This ZIP intentionally excludes local.properties because that file contains device-specific SDK paths.
The project does not configure or require CMake/NDK.
