MAKE MY DAY - MobileStudio Android Project

Prepared for the MobileStudio configuration shown by the user:
- JDK 17
- Gradle 8.2
- Android Gradle Plugin 8.2.2
- Android SDK API 34

This project is a native Android WebView wrapper around the approved MAKE MY DAY V4 interface.

IMPORTANT:
- Do not add local.properties from another device. MobileStudio should provide the SDK path.
- The project does not use NDK or CMake.
- Open the extracted project folder in MobileStudio.
- Use the existing MobileStudio Gradle 8.2 configuration.
